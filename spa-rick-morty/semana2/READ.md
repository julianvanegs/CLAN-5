Este script gestiona un inventario y demuestra el uso de estructuras de datos en JavaScript (Objetos, Set y Map), técnicas de iteración avanzada y validación de datos.

Componentes del Código
Estructuras de Datos: Almacena productos en un Objeto, filtra datos duplicados usando un Set y asocia categorías mediante un Map.

Iteración: Muestra el uso de bucles for...in, for...of, forEach() y métodos nativos como Object.keys(), Object.values() y Object.entries().

Validación: Incluye una función que verifica que cada producto tenga un ID válido, un nombre de texto y un precio numérico mayor a cero antes de permitir su registro.

Cómo Ejecutarlo
Copia el código del script.

Abre la consola de desarrollador en tu navegador (F12).

Pega el código y presiona Enter para ver los resultados en los reportes finales.
